# Original site archive

An HTTrack mirror of the previous NGO Tammana website (`ngotammana.runasp.net`),
captured 31 August 2026, kept verbatim as the source of record.

This branch is **not** part of the site. It has no shared history with `main` and
is never merged — it exists so the original pages and full-resolution photographs
remain recoverable.

The live site is on `main`, rebuilt in Next.js. Its `scripts/extract.mjs` reads a
checkout of this archive placed at `../ngotammana` to regenerate `src/data/*.json`
and the WebP images; running it is optional, since that output is committed.

Contents: 11 page templates, 103 event-detail pages, and 689 original images
(~167 MB of unoptimised JPEG).
